# Kazakh-QWERTZ

QWERTY физикалық пернетақтасында **қазақ тілінде (кириллица)** теруге арналған macOS пернетақта орналасуы. Қазіргі қазақ кирилл әліпбиінің **42 әрпі**, соның ішінде орыс әліпбиінің 33 әрпі, кіші және бас әріп түрінде қолжетімді.

## Орналасу кестесі

QWERTY пернесі → әріп. **32 әріп негізгі қабатта**, ал **қалған 10 әріп Option қабатында** орналасқан. Тыныс белгісі пернелерінің атаулары US QWERTY орындарына сәйкес берілген; JIS пернелеріндегі жазулар өзгеше болуы мүмкін.

```
Жоғ. қатар:  Q=ғ  W=у  E=е  R=р  T=т  Y=з  U=ұ  I=і  O=о  P=п  [=ү  ]=я
Орт. қатар:  A=а  S=с  D=д  F=ы  G=г  H=қ  J=ж  K=к  L=л  ;=ө  '=ә  \=х
Төм. қатар:  Z=и  X=ш  C=ң  V=в  B=б  N=н  M=м
Кері тырнақша: `=й
```

- **Shift** әріптерді бас әріпке ауыстырады: мысалы, `C=ң` → `Shift+C=Ң`.
- **Caps Lock** кирилл әріптерін бас әріпке ауыстырады; цифрлар мен тыныс белгілері өзгермейді. **Shift+Caps Lock** кезінде де әріптер бас әріп болып қалады, ал тыныс белгілері Shift қабатына сай енгізіледі.
- **Option** (⌥) төмендегі қосымша әріптерді енгізеді. **Option+Shift** олардың бас әріптерін енгізеді. Option қабатында бөлек әріп тағайындалмаған әріп пернелері негізгі әріптерін сақтайды.
- **Caps Lock+Option** Option әріптерін бас әріпке ауыстырады, ал Option тыныс белгілері өзгермейді. **Shift+Caps Lock+Option** тіркесімі Shift+Option сияқты жұмыс істейді.
- **Command** тіркесімдері, соның ішінде Shift және Option қосылған тіркесімдер, физикалық QWERTY пернелерінің латын әріптерін пайдаланады. Ағылшынша теру үшін бөлек **ABC/English енгізу көзін** таңдаңыз; Caps Lock енді латын қабатына ауыстырмайды.

### Қосымша әріптер

| Физикалық перне | Option | Option+Shift |
| --- | --- | --- |
| F | ф | Ф |
| H | һ | Һ |
| C | ц | Ц |
| X | щ | Щ |
| E | э | Э |
| O | ё | Ё |
| W | ю | Ю |
| J | ч | Ч |
| B | ь | Ь |
| V | ъ | Ъ |

### Цифрлар мен тыныс белгілері

Цифрлар модификаторсыз енгізіледі. Shift цифрлар қатарының әдеттегі таңбаларын, соның ішінде Shift+6 арқылы ASCII `^` таңбасын енгізеді. Қиғаш сызық пернесі `/`, ал Shift-пен `?` енгізеді. Үтір мен нүкте пернелері `,` және `.` енгізеді; Shift+үтір — `"`, Shift+нүкте — `:`.

Әріптер орналасқан тыныс белгісі пернелерінде Option бастапқы таңбаларды енгізеді:

| Физикалық перне | Option | Option+Shift |
| --- | --- | --- |
| <code>&#96;</code> | <code>&#96;</code> | `~` |
| `[` | `[` | `{` |
| `]` | `]` | `}` |
| `;` | `;` | `:` |
| `'` | `'` | `"` |
| `\` | `\` | <code>&#124;</code> |
| `,` | `«` | `»` |
| `.` | `…` | `…` |
| `-` | `–` | `—` |
| `=` | `≠` | `±` |
| `3` | `№` | `№` |
| `4` | `₸` | `₸` |

Қалған Option+цифр тіркесімдері Shift қосылғанда да цифрларды сақтайды. Бұл мәтіндік қабаттарда **келесі пернені күтетін екпін пернелері жоқ**: әр таңба бірден енгізіледі.

JIS пернетақтасында қосымша иена пернесі де `й` (Shift немесе Caps Lock қосылса, `Й`) енгізеді; Option — `\`, Option+Shift — `|`. Қосымша астыңғы сызық пернесі Shift не Caps Lock қосылса да `_` енгізеді; Option — кері тырнақша, Option+Shift — `~`. Негізгі әріп орындары жоғарыдағы кестеге сәйкес келеді.

## Орнату

```sh
git clone https://github.com/asqatqazet/kazakh-qertz.git
cd kazakh-qertz
./install.sh
```

Содан кейін:

1. **Жүйеден шығып, қайта кіріңіз** (немесе Mac-ты қайта қосыңыз).
2. **System Settings → Keyboard → Input Sources → Edit → +** ашыңыз.
3. Сол жақтан **Kazakh**, оң жақтан **Kazakh-QWERTZ** таңдап, **Add** басыңыз.
4. Меню жолағындағы тіл таңдағыштан ауысыңыз (немесе `⌃Space` арқылы).

## Жою

```sh
./uninstall.sh
```

Қажет болса, **System Settings → Keyboard → Input Sources** ішінен қолмен өшіріңіз.

## DMG арқылы орнату (терминалсыз)

1. [Releases бетінен](https://github.com/asqatqazet/kazakh-qertz/releases) `Kazakh-QWERTZ-<нұсқа>.dmg` жүктеп алыңыз.
2. DMG-ге екі рет басыңыз.
3. `Install.command` файлын екі рет басыңыз. Алғашқы рет macOS рұқсат сұрауы мүмкін — қажет болса *System Settings → Privacy & Security* ішінен рұқсат беріңіз.
4. Жүйеден шығып қайта кіріңіз, содан кейін *System Settings → Keyboard → Input Sources* ішінен қосыңыз.

## Git-сіз орнату

[Releases бетінен](https://github.com/asqatqazet/kazakh-qertz/releases) соңғы zip-ті жүктеп алыңыз, ашыңыз және `Kazakh-QWERTZ.bundle` қалтасын `~/Library/Keyboard Layouts/` ішіне көшіріңіз.

Жаңарту үшін репозиторийді жаңартыңыз немесе жаңа шығарылымды жүктеп алып, `./install.sh` (немесе `Install.command`) файлын қайта іске қосыңыз. macOS бұрынғы орналасуды қолданса, жүйеден шығып, қайта кіріңіз.

## Орналасудың бастапқы файлын тексеру

Тесттерді іске қосыңыз:

```sh
python3 tests/test_coverage.py
```

Тесттер барлық 42 әріптің кіші және бас түрлерін, әр аппараттық картадағы мұраланған сәйкестіктерді, модификаторлардың жұмысын, тыныс белгілерін, физикалық перне тіркесімдерін және қайталанатын перне кодтарын тексереді. Олар орналасудың бастапқы файлын тексереді; оны **орнатпайды** және қолданбадағы нақты жұмысын растамайды.

### Орнатылған орналасуды қолмен тексеру

Орнатқаннан немесе жаңартқаннан кейін мәтіндік редакторда Kazakh-QWERTZ таңдаңыз:

1. `Қазақстан қазақ ыстық ғылым білім жаңбыр әңгіме өрік үшін ұлт үй әй` деп теріңіз. Жаңа `F=ы`, өзгермеген кері тырнақшадағы `й` және `]=я` сәйкестіктерін тексеріңіз.
2. Option арқылы `ф һ ц щ э ё ю ч ь ъ`, одан кейін Option+Shift арқылы `Ф Һ Ц Щ Э Ё Ю Ч Ь Ъ` теріңіз. C және Shift+C арқылы `ң` мен `Ң`, оң жақ жақша пернесі арқылы `я` мен `Я` енгізілетінін тексеріңіз.
3. Caps Lock қосыңыз. Әріптер бас әріп болып, цифрлар мен тыныс белгілері өзгермейтінін тексеріңіз. Shift+Caps Lock, Caps Lock+Option және Shift+Caps Lock+Option тіркесімдерін жоғарыдағы ережелермен салыстырыңыз.
4. `/ ? " :` таңбаларын және кестедегі Option тыныс белгілерін теріңіз. Әр тыныс белгісінен кейін кәдімгі әріпті енгізіңіз: екпін немесе тырнақша келесі пернені күтпеуі керек.
5. Қолданба қолдайтын Command+A, Command+C, Command+V, Command+Z және Command+Shift+Z сияқты физикалық перне тіркесімдерін тексеріңіз. Өзіңіз қолданатын Command+Option тіркесімдерін де тексеріңіз. ABC/English енгізу көзіне ауысып, ағылшынша теріп көріңіз.

Бұл тексеруді өзіңіз қолданатын әр пернетақта түрінде қайталаңыз. Қолданба тіркесімдері мен macOS баптаулары нәтижеге әсер етуі мүмкін. Бұл — қолмен тексеру тізімі; ол жүйе интерфейсінде тексеру жүргізілгенін білдірмейді.
